# Introduction to Software Development:

## Software
1. System software 
2. Application software
3. Network software
 
## Key responsibilities of an entry level Software Engineer:

1. Developing solutions
2. Testing and finalising
3. Fixing errors
4. Coordinating and communicating with a team and stakeholders
5. Learning and teaching new technologies and skills

## 1.Developing Soutions:

- Understand the task that is being asked of you.
- Review existing documentation on the topic
  - (eg: online or inside the company)
- Propose an approach to solve the task.
- Ask questions as needed to clarify task.
- Use coding best practices and design patterns
  - (eg: naming conventions,track changes,version control,consistency throughout code,make code self-explanatory)
- Write code needed for solution.
- Reuse code when appropriate.

## 2.Testing and Finalising solutions:

- Use a DevOps approach to make code reviews along the coding process.
- Have knowledge of/be willing to self-teach about the tests(eg:Unit testing)
- Track code production(Eg: APM to track systems and discover error)
- Test solutions across different softwares.

## 3.Fixing Errors:
- Locate the code that contains error independently or with support from colleagues.
- Test the functionality that has an error.
- Understand the technical details of the current error.
- Test the solution is working correctly.
- Test everything that can be affected by the error(whole system).

## 4.Coordinating and communicating with a team and other stakeholders:
- Participate in and organise team discussions.
   - (eg: Sprint Planning,Daily Scrum,Sprint Retrospective)
- Use team meetings as an opportunity to raise questions and problems.
   - (concerning your own/others work)
- Define situations in which it is acceptable to reach out to a colleague for help vs independent problem-solving.
- Find trusted contact persons who are willing to help.
- Identify desired ways of support provided by selected contact persons.
   - (eg: pair programming,online chat tools like Slack, reviews on GitHub etc)

## 5.Learning and teaching new technologies and skills:
- Having knowledge of/be willing to self-teach about programming language (object oriented & functional development) and any other needed tool.

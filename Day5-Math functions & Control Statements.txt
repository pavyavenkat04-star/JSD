Math Functions:
===============
PI():
	-returns the PI value.
sin():
	-returns sine of an angle.
cos():
	-returns cosine of an angle.
tan():
	-returns tangent of an angle.
ceil():
	-rounds the number up to the nearest integer greater than or equal to the original number.
floor():
	-rounds the number up to the nearest integer smaller than or equal to the original number.
round():
	-rounds the number to the nearest whole number.
sqrt():
	-returns the square root of a number.
abs():
	-converts the negative number to a positive number and the positive number is left unchanged.
max():
	-returns the greatest number out of the given numbers.
min():
	-returns the smallest number out of the given numbers.
exp():
	-returns exponential value of a number.
floorDivExact():
	-calculates the floor division of two integers.

Control Statements:
==================
def: condition based execution

Condition:
	a>34
	mark>=50
	m1>34 && m2>34 && m3>34
	!(m4>=35)
	name.equals("admin") && pwd.equals("password@123")



1.Simple-if:
Syntax:
if(condition)
{
statement;
}


Eg:
if (mark>34)
{
System.out.println("Pass");
}

2.If-else:
Syntax:
If (condition)
{
true statement;
}
else
{
false statement;
}


Eg:
if (marks>34)
{
System.out.println("Pass");
}
else
{
System.out.println("Fail");
}
	
3.If-else-if statement:
Also known as else if ladder.
def'n: 
	infinite chance
Syntax:
if(condition1)
{
statement1;
}
else if(condition2)
{
statement2;
}
else if(condition3)
{
statement3;
}
.....
.....
else
{
else statement
}

4.Nested if:
def:
	-If statement within if statement
Syntax:
if (condition)
{
if (condition)
{
statement;
}
}

import java.util.Scanner;
public class EbBill {
    public static void main(String[] args) {
        Scanner scan=new Scanner(System.in);
        System.out.println("Enter no of units:");
        int units=scan.nextInt();
        scan.close();
        float amnt=0f;
        float amnt1=0f;
        float amnt2=0f;
        if(units<=500)
        {if(units<=200)
            amnt=0;
            else if(units>=201 && units<=400)
                amnt=(units-200)*4.70f;
            else 
                amnt1=200*4.70f;
                amnt2=(units-400)*6.30f;
                amnt=amnt1+amnt2;
        }
        else
        {
                amnt=(units-500)*8.40f+300*4.70f+100*6.30f;  
        }
        System.out.println("No of units used:"+units);
        System.out.println("EB Bill amount:"+amnt);
    }
}

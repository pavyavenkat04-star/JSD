# HTML
- HTML stands for HyperText Markup Language
- Invented by Tim Berners Lee in the year 1990.
- Purpose:To design webpage
- HTML is not a case sensitive language.
- Extension:.html
- Editors:
    - notepad
    - sublime
    - dreamviewer
    - vs code
- Advantage:Does'nt show any errors.
- Output:
   - any web browser
   - internet explorer
   - google chrome
   - Firefox
   - safari
   - opera
   - netscape navigator

- HTML is divided into two sections
1. Header section
    - title
    - image icon
    - base
    - meta
    - css
    - javascript
    - jquery
    - bootstrap cdn
2. Body section
    - use html tags
    - `<body>`
    - header,font,text,paragraph,images,list,tables,link,form,frameset,animation,audio,video
    - `</body>`

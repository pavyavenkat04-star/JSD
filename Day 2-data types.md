# Java Data Types:

## Numbers:
	byte		1byte=8bits		2^8=256/2		-128 to 127
	short		2byte=16bits		2^16=65536/2		-32768 to 3276
	int		4bytes=32 bits		2^32=4294967296/2 	-2147483648 to 2147483647
	long		8bytes=64bits   	2^64=			-9223372036854775808 to 92233772036854775807    

## Decimal:
	float	4bytes	8digits
	double	8bytes	17digits

## Text:
	char	1byte	
	String 	infinite	

## True/False:
	Boolean	1bit 


**Program:**
```java
package jsd;

public class Testdata 
{
public static void main(String[] args) 
{
 byte b=120;
 System.out.println(b);
 short s=5003;
 System.out.println(s);
 int i=1234456;
 System.out.println(i);
 long l=130000000l;
 System.out.println(l);
 float f=5.24f;
 System.out.println(f);
 double d=4.7890232;
 System.out.println(d);
 boolean isJavaFun=true;
 System.out.println(isJavaFun);
 char c='q';
 System.out.println(c);
 String fer="question";
 System.out.println(fer);
	}
}
```

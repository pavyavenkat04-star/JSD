# MongoDB
## Introduction
- MongoDB is a open source,document oriented(paragraph format)
- Database stores data in the form of documents in key:value pairs
- **document based eg:**
    - var stud={rno:1001,name:"riya",age:30,hobbies:[cricket,chess,tennis,badminton]}
- **Nested json:**
    - var emp:{eno:1,ename:"riya",designation:"MCA",prev_emp_location:{city1:"Karur",city2:"Trichy"...}}
- This is a json like structure where data is stored in the form of key-value pairs.

## History of MongoDB
- MongoDB was created by Eliot and Dwight in 2007 while facing scalability issues while working with relational databases.
- The organisation that developed MongoDB was originally known as 10gen
- In Feb 2000,they changed their business model and released MongoDB as an open source project.
- The organisation changed its name in 2013 and now known as MongoDB Inc.

## Features of MongoDB
- MongoDB provides high performance.Most of the operations in the MongoDB are faster compared to the relational database(RDBMS).
- MongoDB provides auto-replication feature that allows you to quickly recover data in case of a failure.
- Horizontal scaling is possible in MongoDB because of sharing.Sharing in partitioning of data and placing it on multiple machines in such a way that the order of the data is preserved.
- Vertical Scaling is not possible in MongoDB.

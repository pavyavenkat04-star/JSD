Preference of CSS - Inline

After checking for inline css, it gives preference to the recently mentioned style.
Eg:internal style css applied in line 8 external css applied in line 10. the actual line (h1) is present in line 11.
The output would be displayed as follows: The h1 content is displayed with the inline style at first if mentioned .If inline style is not mentioned it checks for the most recent style applied to the tag and follows the style.

# Javascript
- Javascript was invented in 1995 by Brendan Eich
- Original name:"livescript"
- Javascript is a case sensitive language.
- Javascript extension:.js
- Firstly worked only in netscape navigator 2.0
- Since 1996, works in all of the browsers.
- Main Purpose:
    - directly interacts with html codes.
    - For validation.
- Java and Javascript are different.
- Joining operator:+ or concatenation operator.
- Javascript is an interpreter.
- Javascript is a loosely typed language.
    - var a=10; ----->integer
    - var b=10.20; ----->float
    - var c="text@123"; ----->string

## General Format
```html
<html>
<head>
<title>...</title>
<script type="text/javascript>
....
</script>
</head>
<body>
....
</body>
</html>
```
